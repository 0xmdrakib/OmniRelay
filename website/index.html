HOW OMNIRELAY WORKS

Simple for people. Deliberate underneath.

  1. 1

    Pair intentionally

    Exchange a Secret Link out of band and add a trusted contact by name.

  2. 2

    Encrypt locally

    The sender authenticates the destination and encrypts the payload on-device.

  3. 3

    Choose a viable path

    Internet, Wi-Fi Aware, or BLE is selected according to reachability and policy.

  4. 4

    Confirm the real state

    Delivery and call transitions advance only after valid authenticated events.

SECURITY IS THE ARCHITECTURE

Relays move ciphertext—not conversations.

OmniRelay separates identity, route authorization, and payload encryption so intermediate devices can forward bounded capsules without receiving message content.

HONEST CONNECTIVITY

A message still needs a path.

No app can reach a device that has no internet and no nearby radio or connected relay route. OmniRelay is designed to use every legitimate available path—not to claim one exists when it does not.
